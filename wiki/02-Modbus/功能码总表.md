## 功能码总表

| 功能码 | 操作                      | 数据区           | 权限 |
| ------ | ------------------------- | ---------------- | ---- |
| `01`   | 读取多个 Coil             | Coil             | 读   |
| `02`   | 读取多个 Discrete Input   | Discrete Input   | 读   |
| `03`   | 读取多个 Holding Register | Holding Register | 读   |
| `04`   | 读取多个 Input Register   | Input Register   | 读   |
| `05`   | 写一个 Coil               | Coil             | 写   |
| `06`   | 写一个 Holding Register   | Holding Register | 写   |
| `0F`   | 写多个 Coil               | Coil             | 写   |
| `10`   | 写多个 Holding Register   | Holding Register | 写   |

记忆方法：

```
01–04：读取
05、06：写单个
0F、10：写多个
```



## 异常响应

当服务器不能正常处理请求时，不返回普通响应，而是返回异常响应。

计算方式：

```
异常功能码 = 原功能码 + 0x80
```

也可以写成：

```
异常功能码 = 原功能码 OR 0x80
```

例如：

| 原请求功能码 | 异常功能码 |
| ------------ | ---------- |
| `01`         | `81`       |
| `02`         | `82`       |
| `03`         | `83`       |
| `04`         | `84`       |
| `05`         | `85`       |
| `06`         | `86`       |
| `0F`         | `8F`       |
| `10`         | `90`       |

异常响应格式：

```
异常功能码 + 异常码
```

## 常见异常码

| 异常码 | 含义                     |
| ------ | ------------------------ |
| `01`   | 不支持该功能码           |
| `02`   | 地址不存在或访问范围越界 |
| `03`   | 数量、格式或写入值不合法 |
| `04`   | 设备内部处理失败         |

例如客户端发送：

```
03 00 64 00 01
```

请求读取 Holding Register 地址 100，但设备只实现地址 0–20。

服务器可以返回：

```
83 02
```

解释：

```
83    功能码 03 的异常形式
02    Illegal Data Address
```
