## 四类数据对象与地址问题

### 四类基本数据对象

| 数据对象          | 位宽   | 通常权限 | 传统编号表示 |
| ----------------- | ------ | -------- | ------------ |
| Coils             | 1 bit  | 读写     | 0xxxx        |
| Discrete Inputs   | 1 bit  | 只读     | 1xxxx        |
| Input Registers   | 16 bit | 只读     | 3xxxx        |
| Holding Registers | 16 bit | 读写     | 4xxxx        |

### 四类对象在泵站中的映射

#### Coils

适合表示可以写入的布尔控制量：

- 启动泵命令。
- 停止泵命令。
- 阀门开关命令。
- 告警复位。

#### Discrete Inputs

适合表示只读布尔状态：

- 泵正在运行。
- 阀门已打开。
- 高液位开关触发。
- 急停触发。
- 设备故障。

#### Input Registers

适合表示只读测量值：

- 当前水位。
- 当前压力。
- 当前流量。
- 电机电流。
- 环境温度。

#### Holding Registers

适合表示可配置参数或可写数值：

- 目标水位。
- 高液位阈值。
- 低液位阈值。
- 泵速设定。
- 工作模式。



**为什么 Modbus 有四类数据区**

Modbus 使用两个问题对变量进行分类：

1. 变量是布尔值还是数值？
2. 变量是只读还是可写？

由此得到四种组合：

|           | 只读           | 可读写           |
| --------- | -------------- | ---------------- |
| 布尔值    | Discrete Input | Coil             |
| 16 位数值 | Input Register | Holding Register |

这就是四类数据对象的逻辑来源。



### 地址

每个数据区都可以理解成一张独立的表。

```
Coil 表
地址 0
地址 1
地址 2
...

Discrete Input 表
地址 0
地址 1
地址 2
...

Input Register 表
地址 0
地址 1
地址 2
...

Holding Register 表
地址 0
地址 1
地址 2
...
```

四张表都可以有地址 0。

因此，单独说“地址 0”没有意义，还必须同时知道访问的是哪张表。

例如：

```
Coil 地址 0
```

和：

```
Holding Register 地址 0
```

完全是两个不同的对象。



### 谁决定访问哪张表

功能码决定访问哪张表：

| 功能码 | 数据区           |
| ------ | ---------------- |
| `0x01` | Coil             |
| `0x02` | Discrete Input   |
| `0x03` | Holding Register |
| `0x04` | Input Register   |

所以：

```
功能码决定哪张表
地址决定表中的哪一行
```

这是理解 Modbus 地址的关键。



### 40001、30001 这些数字是什么

这是最容易混乱的地方。

传统 Modbus 文档经常使用下面的编号：

| 传统编号     | 数据区           |
| ------------ | ---------------- |
| `00001` 开始 | Coil             |
| `10001` 开始 | Discrete Input   |
| `30001` 开始 | Input Register   |
| `40001` 开始 | Holding Register |

这些主要是文档中的“参考编号”，不是直接放进网络报文的地址。

例如：

```
文档编号：40001
```

通常表示：

```
Holding Register 的第一个寄存器
```

它在 PDU 中的地址通常是：

```
0
```

请求是：

```
功能码 03 + 地址 0
```

而不是：

```
功能码 03 + 地址 40001
```

### 对应关系

| 文档表示 | 数据区           | 常见 PDU 地址 |
| -------- | ---------------- | ------------- |
| `00001`  | Coil             | 0             |
| `10001`  | Discrete Input   | 0             |
| `30001`  | Input Register   | 0             |
| `40001`  | Holding Register | 0             |
| `40002`  | Holding Register | 1             |
| `40010`  | Holding Register | 9             |

可以这样记：

> `4` 表示 Holding Register 区域，后面的编号表示它在该区域中的位置。

但要注意，有些厂商文档直接使用从 0 开始的地址，有些从 1 开始。因此拿到设备手册时必须确认地址规则。
